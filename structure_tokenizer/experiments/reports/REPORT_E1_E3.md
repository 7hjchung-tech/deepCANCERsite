# E1 · E3 — 구조만으로 어디까지 / 인코딩 5가지 비교

- 완료된 모델: GBDT, L, PLR, Q, Qk, Qk-shuf, T, TYPE
- 미완료/없음(제외): 없음 
- repeat 2 × outer 5-fold, 모든 행이 repeat 마다 한 번씩 test
- 주 지표 subset = mean(Spearman_missense, Spearman_indel). **바깥 fold 마다 계산해 평균** (Forman & Scholz 2010). 괄호는 position cluster bootstrap 95% CI (2000회). synonymous 는 해석하지 않음 (명세 §7.4)
